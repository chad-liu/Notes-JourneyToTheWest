一、先理解：《西遊記》的時間不是單純的一條線

《西遊記》是一部把 歷史、佛教、道教、民間神話與小說想像 融合在一起的作品。

為什麼孫悟空的故事，會發生在唐僧出生之前？

因為《西遊記》存在不同層次的時間。

孫悟空的大鬧天宮，是「神話時間」； 唐僧取經，是「唐朝歷史背景」； 八十一難，則是「小說敘事時間」。

因此，閱讀《西遊記》時， 不能把所有事件都當成同一種歷史時間。

九、課堂思考題

問題一： 為什麼孫悟空的故事發生在唐僧出生之前？
問題二： 《西遊記》中的玄奘與歷史上的玄奘，有哪些相同與不同？
問題三： 為什麼觀音菩薩可以同時出現在神話世界與取經故事中？
問題四： 「大鬧天宮」與「西天取經」分別代表孫悟空生命中的哪兩個階段？
問題五： 八十一難只是冒險故事，還是具有「修行」的象徵意義？
問題六： 如果刪掉「大鬧天宮」，孫悟空還會是我們今天熟悉的孫悟空嗎？

十、全書時間軸一句話總結

《西遊記》的故事可以濃縮成：

仙石誕猴 → 求道學藝 → 大鬧天宮 → 五行山受困 → 唐僧出世 → 觀音組隊 → 西天取經 → 八十一難 → 靈山取經 → 功德圓滿

但更深層的閱讀方式是：

孫悟空 反抗
五行山 限制
取經 修行
八十一難 考驗
成佛 覺悟

因此，《西遊記》的時間軸不只是： 「發生了什麼事」， 也可以理解成： 「一個人如何經歷磨難、完成修行，最後改變自己」。
